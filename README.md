# Lebensrad

Reflexionsinstrument aus der IfYouChange-Mastermind: die eigenen Lebensbereiche
benennen, ausmalen, definieren was 100 % wären, und daraus die Vorbereitung für
die Zielsetzung ableiten.

Eine einzelne HTML-Datei, ohne Server und ohne Konto. Alles bleibt im Browser des
Nutzers (`localStorage`), es wird nichts übertragen. Gebaut aus
`scripts/build_lebensrad_kern.py` im AIOS-Workspace.

**Testrunde:** `noindex` im Kopf und `robots.txt` sperren Suchmaschinen aus.
Vor dem öffentlichen Start beides entfernen.
